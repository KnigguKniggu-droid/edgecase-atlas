# Public launch checklist

Every checkbox requires a traceable artifact or direct observation. Leave unknown items unchecked.

## Repository and identity

- [ ] Public repository works while logged out.
- [ ] Default branch and release tag point to the reviewed commit.
- [ ] Public CI passes from a clean wheel installation.
- [ ] Authors, committers, messages, tags, blobs, issues, and release metadata pass identity scans.
- [ ] Profile, repository, release, and rendered pages expose no private identity or affiliation.
- [ ] License, README, dataset card, model card, threat model, and disclaimer render correctly.

## Hosted application

- [ ] Anonymous deployment authentication is complete.
- [ ] Public URL is recorded in the private metrics ledger.
- [ ] Logged-out cold start succeeds.
- [ ] No-key demo creates and downloads a certificate.
- [ ] Timeout, concurrency, rate, call-budget, text-length, and artifact-size limits are active.
- [ ] Errors reveal no secret, local path, stack trace, account identifier, or raw IP address.
- [ ] Keyboard-only and narrow-screen checks pass.
- [ ] A second network confirms the public smoke test.

## Evidence and pilots

- [ ] Analytics count completed runs, distinct pseudonymous users, and repeated users as documented.
- [ ] Analytics exclude raw IPs, names, emails, uploaded files, and location traces.
- [ ] At least five relevant adults receive individualized invitations.
- [ ] Feedback records contain pilot codes, consent, workflow evidence, and no contact details.
- [ ] Public aggregates include only consented responses.
- [ ] Every published number reconciles to the frozen evidence cutoff.

## Competition assets

- [ ] Story is generated from validated metrics and contains at most 150 words.
- [ ] Video follows the shot list and lasts at most 60.0 seconds.
- [ ] Captions, links, replay command, and downloads are legible.
- [ ] Video frame audit finds no private or unsupported material.
- [ ] Submission fields are complete and independently checked.
- [ ] Final private application receives explicit user approval before submission.
