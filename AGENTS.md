# Repository rules

- Keep every public artifact anonymous. Use only the project name and a GitHub noreply identity.
- Never add personal names, personal email addresses, private affiliations, mentor details, or location traces.
- Never copy files, prompts, scenarios, results, or prose from unrelated local autonomy research.
- Never commit API keys, tokens, model weights, `.env` files, or Streamlit secrets.
- Keep private model paths behind `LLAMA_MODEL_PATH` and never copy model files into this repository.
- Use newly written synthetic fixtures or clearly licensed public records.
- Treat all safety properties as editable operational assumptions, not universal laws or certification rules.
- Describe this project as simulated research and debugging software, not a vehicle controller.
- Make all application changes test-first and run focused tests before the full suite.
- Keep generated runs, certificates, reports, and raw research data out of Git unless deliberately curated and identity-scanned.
