# Dataset and model card templates

## How to use this file

This file holds two blank templates. `docs/dataset-card.md` and `docs/model-card.md` are the filled
cards for the current alpha and are the worked examples to read alongside these.

Copy the relevant block to `research/cards/<name>-dataset-card.md` or
`research/cards/<name>-model-card.md` and fill it. Rules:

- Replace every `<...>` placeholder or mark it `not applicable` with a reason.
- A results field with no run behind it stays `TBD`. Do not write a plausible number.
- No personal name, institution, mentor, email address, or local filesystem path anywhere.
- Do not invent a license. Copy the license that the source actually carries.
